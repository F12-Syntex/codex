## 2025-02-18 - Database Prepared Statement Overhead
**Learning:** SQLite prepared statements (`db.prepare()`) in `better-sqlite3` incur significant overhead if parsed repeatedly inside loops, especially within complex write transactions like `mergeWikiEntries` and `mergeArcs`.
**Action:** Always extract `db.prepare()` outside of loops. Reusing the statement inside the loop via `.run()` eliminates redundant parsing overhead and prevents N+1 query bottlenecks without altering database structure or dependencies.
